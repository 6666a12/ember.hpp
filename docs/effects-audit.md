# 效果逻辑检查与修复（2026-09-17）

本次检查覆盖当前 GL 后端的出生、运动、绘制和效果组合。新增 `tests/effects.hpp`，由模块化与单头文件两个 GL 测试共同执行。修复依据是数值结果、像素/深度读回和源码契约；以下问题均补了回归，玻璃示例的配置优先级另做源码检查与编译验证。

## 已确认并修复

| 范围 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 噪声风、波浪 | 负振幅会打开力开关，但 shader 用 `> 0` 跳过计算 | 负振幅反转作用方向，零振幅关闭 |
| 地面反弹 | 已向上运动、仍位于平面下的粒子再次被反射向下 | 将位置约束到平面，只反射向下速度 |
| 速度保护 | 先更新位置、再限速，强力场仍能造成巨大位移 | 先限制速度，再积分位置 |
| 自旋与拉伸 | 负自旋不生效；折射静态角及 streak 下的穹顶坐标与 quad 不一致 | 支持正反自旋，静态折射面片和穹顶按实际 quad 朝向绘制；零横向速度有确定方向 |
| 投影 | 写死 `viewZ > -0.01` 剔除合法粒子 | 由传入投影矩阵决定裁剪，支持更近的透视近平面及跨过视图原点的正交范围 |
| 混合 | 继承宿主减法等混合方程，粒子与 Bloom 可能变黑 | 绘制明确使用加法方程，并保留既有两种混合因子 |
| 面剔除 | 宿主面剔除可以让 billboard 和 Bloom 全屏三角形消失 | 内部禁用面剔除，结束恢复宿主开关 |
| Bloom 裁剪 | 宿主 scissor 误用于半分辨率纹理，可能保留上一帧内容 | 中间纹理完整清理和处理，最终宿主输出仍遵守 scissor |
| 软粒子/透明片元 | 完全透明的片元仍能写深度，遮住之后的物体 | 零 alpha 片元丢弃；软半径拒绝非有限值和非正数，配置校验在扩容前完成 |
| 默认贴图恢复 | 文档允许 `texture=`，解析器却拒绝空值，应用层也跳过 | 显式空路径恢复内置贴图；其他数值键继续拒绝空值 |
| 图集动画 | 双线性采样跨到相邻动画帧，边缘串色 | 当前帧 UV 限定在该格的半 texel 边界内 |
| 深度折射 | `ior` uniform 从未参与计算 | 按折射率弯折视线，与场景深度平面求交并投影；`ior=1` 无偏折，非正/非有限值被拒绝 |
| 折射透明度 | 忽略粒子 alpha、寿命和遮罩覆盖度，透明粒子仍覆盖画面、死亡时突变 | 三者控制折射与反光的覆盖度，逐渐混回场景原色；零覆盖度不写颜色或深度 |
| 折射深度策略 | 总是关闭深度测试，忽略 `setDepthTest` / `setDepthWrite` | 遵守系统显式深度策略，默认仍关闭；开启后能被前景遮挡 |
| 玻璃示例热加载 | `applyPreset` 覆盖配置指定的折射模式 | 初次加载和 R 重载尊重配置；G 切换仍选择预设自身模式 |

## 仍然保留的效果边界

- 折射仍是单层屏幕空间近似：采样宿主提供的场景颜色，最后覆盖输出。重叠碎片依赖绘制顺序，不会递归折射之前绘制的碎片或 Bloom；需要远近顺序时启用排序。宿主颜色纹理应包含期望被折射的内容。
- 深度纹理重建使用标准 OpenGL `[-1,1]` 裁剪深度、默认 depth range、非 reversed-Z。颜色/深度输入对应 `(0,0,width,height)` 视口。没有场景深度纹理时，depth 折射仍回退 simple；有纹理但某像素深度为 1 时，用单位距离背景平面近似。
- depth 模式的 `strength` 现在缩放投影后的物理偏移；simple/noise 模式仍按 UV 偏移解释，旧 depth 模式外观会变化。
- 折射不参与 Bloom 提亮链，依靠自身的 Fresnel/specular；明显的 streak 优先于自旋，低速过渡与后续专项检查见 [拖尾说明](streak.md)。
- 运动仍用半隐式 Euler，`dt` 最大 0.1 秒。高刚度弹簧或极强阻尼需要合适步长；速度保护不能替代稳定积分器。球形发射仍采用均匀半径采样，中心密度较高，未改成均匀体积分布。
