# 性能优化前后对比

同一台 RTX 4060 Laptop、驱动 595.71、Release、1280×720 离屏，workload v1 保持不变。每个场景预热 120 帧、测量 240 帧、重复 3 次；普通库、分阶段插桩、关闭 GPU 时间戳三个组共 297 个 case / 71,280 帧，全部通过校验。

主要比较**整个测量窗口直到 GPU 完成的平均每帧时间**，包含目标清空、提交、查询采集和最后一次 drain。不是显示帧率，也不把 CPU 等待等同于 GPU 计算。单位为 ms；倍数为旧耗时 / 新耗时。

## 改动与证据

1. **排序缓存深度键，并在 256 项 tile 内合并比较步骤。** 仍为每帧完整的远到近 bitonic 排序，相同深度按稳定槽位编号打破平局。百万粒子从 211 次 dispatch（含初始化）降到 91 次，同时消除每次比较重复读取粒子/计算视图深度的成本。分阶段组 GPU sort P50 从 56.465 ms 降到 2.097 ms。

2. **一次预留整帧出生所需的回收/追加槽位。** phase 3 在积分结束后用单 invocation 更新计数，出生线程按工作索引访问互不重叠的槽位。保留稳定槽位和回收优先策略，容量不足时按请求顺序接受前缀；不再由每个出生线程竞争全局 CAS。百万容量 churn 的 GPU spawn P50 从 4.330 ms 降到 0.013 ms。

3. **按双缓冲存活索引积分。** 幸存者和新粒子直接构建下一帧索引；最后的 phase 2 只发布间接绘制数量。历史分配过百万但仅剩一万粒子时，工作量随存活量下降。退休时给两份粒子缓冲写墓碑，保留按槽位读取以及旧版自定义仿真的兼容性。

同步读回仍为前五个计数器的 20 B；aliveCount() 仍反映最近一次 update。没有改变混合、Bloom 或折射效果，没有降低排序频率或切换到近似 OIT。

## 小负载的交替复核

完整矩阵的部分小负载出现几十微秒的波动，因此额外以旧→新→新→旧的顺序串行复核，关闭 GPU 时间戳，每场景预热 120 帧、测量 480 帧、重复 3 次。旧程序从独立工作目录运行，使用对应版本的内嵌仿真/绘制 Shader，避免误加载新协议 Shader。原始数据、程序/Shader 哈希、命令和遥测保存在 small-load-abba-validated/。

| 容量 | 场景 | 旧版完成时间 | 新版完成时间 | 旧 / 新 |
|---:|---|---:|---:|---:|
| 10000 | dense | 0.0712 | 0.0655 | 1.087× |
| 10000 | sparse | 0.0547 | 0.0500 | 1.095× |
| 10000 | sparse_control | 0.0532 | 0.0516 | 1.032× |
| 10000 | refraction_depth | 0.0827 | 0.0789 | 1.049× |
| 10000 | bloom | 0.2163 | 0.2208 | 0.980× |
| 100000 | dense | 0.1877 | 0.1835 | 1.023× |
| 100000 | sparse | 0.0759 | 0.0537 | 1.412× |
| 100000 | sparse_control | 0.0522 | 0.0525 | 0.994× |
| 100000 | refraction_depth | 0.2488 | 0.2477 | 1.004× |
| 100000 | bloom | 0.4378 | 0.4413 | 0.992× |

复核没有显示小负载的统一加速：例如一万容量 Bloom 平均约慢 2%，其他部分场景基本持平。该轮优化的明确收益集中在排序、出生洪峰和稀疏高水位扫描；不能把所有场景都宣称为加速。笔记本未锁频，电源和温度差异仍会影响小数值。

## 成本、兼容性与验证

- 存活索引双缓冲额外使用 capacity × 4 B；排序深度键按需分配，最多 nextPow2(capacity) × 4 B。百万容量约额外 4 MB，开启并填满排序键缓存后合计额外约 8.2 MB。

- binding 4 在五字段前缀后增加三个 uint（总计 32 B，仍只读回 20 B）；binding 12 在仿真时绑定下一帧索引，排序时绑定独立深度键缓存。声明 uInputAlive / uTileMode 的自定义 Shader 必须遵守完整新协议。缺少这些 uniform 的旧仿真/排序 Shader 保留原调度路径，迁移细节见 INTEGRATION.md。

- 新增 GPU/CPU 排序对照，覆盖 1/63/64/65/255/256/257/511/512/513/4093/65537 个粒子、非二次幂填充、相同深度、前后视图、死亡空洞，以及排序后继续仿真。

- 批量分配验证回收与追加混用、超容量、长期稀疏、反复回收、移动对象和改变容量；同时验证 live/free 集合不重叠、不重复、不丢失，计数与间接参数一致，旧新 Shader 双向切换不复活尸体。

- 编辑器开启构建 7/7 项测试通过，关闭构建 6/6 项通过；模块版、单头文件和内嵌 Shader 同步验证通过。本轮 GPU 实测仅覆盖该 NVIDIA 设备，其他厂商驱动尚待验证。
